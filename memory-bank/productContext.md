# PALABA - Product Context

## Problem Statement
Many existing social networks are not optimized for African mobile users, with high data usage, limited device compatibility, and interfaces not designed for mobile-first experiences.

## How It Works
- Users scroll through a vertical feed of short-form videos
- Users can create and share video, text, and audio content
- Bottom navigation provides quick access to Home, Discover, Create, Messages, and Profile
- Content is stored and served via Supabase

## User Experience Goals
- Mobile-first design with touch-friendly interfaces
- Vertical video scroll similar to TikTok
- Fast loading optimized for mobile networks
- Intuitive bottom navigation bar
- Brand colors: purple (#4A0E5C), orange (#F59E0B), gold (#D4AF37)

## Key Features (Phase 1)
- Bottom navigation bar (Home, Discover, Create, Messages, Profile)
- Video feed placeholder with sample content
- Dark purple theme for mobile interface
