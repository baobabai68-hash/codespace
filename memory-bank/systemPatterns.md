# PALABA - System Patterns

## Architecture
- Next.js App Router with src directory structure
- Client-side rendering for mobile app-like experience
- Supabase as backend (database, authentication, storage)

## Key Components
- **Layout**: Root layout with mobile-first bottom navigation bar
- **Page**: Home page with vertical video feed
- **Navigation**: Bottom nav bar with 5 items (Home, Discover, Create, Messages, Profile)

## Design Patterns
- Mobile-first responsive design
- Bottom navigation pattern (mobile app style)
- Vertical scroll feed pattern
- Card-based content display

## Color System
- Primary: Dark Purple (#4A0E5C) - navigation, headers, primary actions
- Accent: Orange (#F59E0B) - CTAs, highlights, active states
- Secondary: Gold (#D4AF37) - accents, decorations, premium elements
