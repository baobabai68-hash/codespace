# PALABA - Project Brief

## Overview
PALABA is a mobile-first social network for Africa with a TikTok-style video feed. The platform supports video, text, and audio content sharing.

## Core Requirements
- Mobile-first social network optimized for African markets
- TikTok-style vertical video feed
- Support for video, text, and audio posts
- Built with Next.js, Tailwind CSS, and Supabase
- Visual identity: purple (#4A0E5C), orange (#F59E0B), gold (#D4AF37)

## Project Goals
- Phase 1: Set up project foundation (this phase)
- Create mobile-responsive social media interface
- Implement video feed with swipe navigation
- Set up Supabase database for user content and profiles

## Target Users
- Mobile users in Africa
- Content creators and consumers
- Social media users preferring short-form content
